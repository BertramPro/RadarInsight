# 论文配置记录

## 研究定位

本文以《基于外辐射源雷达航迹运动特征的无人机与飞鸟识别》提出的任务为基础，研究外辐射源雷达低慢小目标的分类识别问题，并将单一航迹运动特征识别扩展为航迹（TR）与距离-多普勒图（RD）双分支识别。

拟研究问题：

> 在固定航迹级数据划分和统一评价协议下，RD 图像与航迹运动特征是否具有互补判别能力？基于两路预测质量的航迹级门控融合，能否改善五类低慢小目标的总体识别性能及 Bird/Unknown 易混淆问题？

## 章节风格依据

参考论文普遍采用“0 引言、1 数据或信号预处理、2 特征/模型方法、3 实验与分析、4/5 结束语”的组织方式。本文保留这一中文核心论文风格，但将方法和实验章节拆得更清楚，以便分别交代 TR、RD 和融合协议。
