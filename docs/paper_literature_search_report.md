## 初步研究空白

1. 现有航迹研究多将航迹作为主要或唯一输入，较少在同一航迹级评价协议下，与 RD 图像分支进行严格配对比较。
2. 多域融合研究常关注特征拼接或网络结构，较少报告 TR 和 RD 两路各自判断、错误互补性以及融合造成的 rescue/harm 样本变化。
3. Bird/Unknown 等边界类别的评价容易受样本数和划分影响，不能只报告总体 Accuracy；需要保留类别 F1、混淆矩阵和具体错例。
4. 门控融合必须使用训练集 OOF 分数，验证集用于方案选择，测试集只用于最终评估；这一防泄漏约束需要在方法和实验章节明确写出。
5. 文献中的 SMOTE 多用于训练样本平衡。对于本项目的验证/测试扩增，只能作为独立的虚拟航迹稳定性诊断，不能替代原始分区指标。

## 文献与本项目结果的关系

- 文献结论：说明已有方法和研究动机；
- 本项目原始分区结果：用于论文的主要实验结论；
- 分区内虚拟航迹结果：仅作为扰动鲁棒性或少数类稳定性诊断；
- 尚未完成的 SMOTE 或新门控实验：不得写成已验证的性能提升。
