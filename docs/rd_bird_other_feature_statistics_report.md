# Bird / Other（Unknown）航迹特征统计报告

## 材料信息

- 分析对象：R0-900 Global、R2-900 Contrast
- 验证划分：固定 `registry_train`
- 验证航迹数：232
- 随机种子：42
- 分析单位：航迹级，帧级特征先计算后聚合
- 验证状态：`ANALYZED`

## 四类特征定义

1. **近零速度能量比例**：将 RD 的 dB 值转换为相对功率后，计算 `|Vr| <= 10 m/s` 区域功率占整幅 RD 功率的比例。
2. **速度响应宽度**：对每帧沿 RD 行取最大响应，使用相对背景的半峰值阈值，计算峰值连续响应区间的物理速度宽度。
3. **局部对比强度**：沿速度轴用约 4% 宽度的滑动窗口计算局部速度对比，记录正对比峰值和最高 5% 对比值的均值。
4. **多帧形态稳定性**：计算每帧速度响应剖面与该航迹平均剖面的余弦相似度，同时记录相邻帧剖面的余弦相似度、峰值速度标准差和响应宽度变异系数。

## 主要发现

### 1. 速度响应宽度是当前最有价值的候选特征

正确 Bird 的速度响应明显更窄，Bird -> Other 错例则更宽：

- R0-900：`1.492 m/s` 对 `4.162 m/s`；
- R2-900：`1.782 m/s` 对 `3.359 m/s`。

这与“鸟类具有更集中速度响应”的假设一致。它比简单的近零速度能量比例更有区分度，适合作为后续 Bird/Other 辅助特征或辅助损失的候选输入。

### 2. 近零速度能量比例不能单独作为 Bird 判据

两个模型中，正确 Bird 的比例都约为 `0.655`，但 Bird -> Other 和正确 Other 的比例更高。仅凭“中心速度能量越多越像 Bird”会把部分 Other 样本误判为 Bird 或反过来，不能作为单独决策规则。

### 3. 多帧稳定性没有表现为鸟类独有特征

R2-900 中 Bird -> Other 的平均航迹内相似度为 `0.985`，高于正确 Bird 的 `0.930`。这说明部分错例不是因为形态随时间剧烈变化，而是以稳定的、但更宽的错误形态持续出现。单独增加时间稳定性约束可能不能解决该边界。

### 4. 局部对比强度需要结合响应宽度使用

R0-900 中 Bird -> Other 的局部对比峰值低于正确 Bird；但 R2-900 中两者差异缩小，且 Other -> Bird 的对比峰值最高（`4.878`）。因此局部对比强度本身不是稳定的 Bird 特征，更适合作为“窄度 + 峰值形态”的组合特征。

### 5. Other -> Bird 是另一种少量但不同的错误模式

R2-900 的两条 Other -> Bird 航迹表现为很窄的响应（`0.954 m/s`）、很高的局部对比峰值（`4.878`）和较低的峰值速度波动（`0.195 m/s`）。它们更像“稳定、尖锐的 Bird-like Other”，与 Bird -> Other 的“宽响应 Bird”不是同一类错误。

## 结论与下一步

当前不应只强化一个笼统的“鸟类特征”。更合理的方向是构造 Bird/Other 的双向边界特征：

- 对 Bird -> Other，重点关注响应宽度过宽的问题；
- 对 Other -> Bird，重点识别过窄、过尖且稳定的 Bird-like Other；
- 以响应宽度为主，结合局部对比峰值和多帧稳定性，而不是直接使用近零能量比例。

下一步可以在 R2-900 上增加航迹级 Bird/Other 辅助特征或 pairwise margin，并将以下指标作为主要评价：

```text
Bird -> Other + Other -> Bird
Bird F1
Other F1
Macro-F1
```

本分析是单 seed、单次运行的探索性统计。Bird -> Other 和 Other -> Bird 错例数量很少，不能据此宣称已经得到稳定的物理判别规律；应在增加辅助特征后使用同一固定划分重新验证。
