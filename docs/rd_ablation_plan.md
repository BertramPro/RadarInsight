# RD 五分类消融实验方案

## Material Passport

- ID: `RD-ABLATION-PLAN-20260807`
- Type: RD-only 五分类消融实验计划
- Scope: `data_proc_MTD_result_db` + 每文件 `Vr`
- Baseline: R1 轻量 2D CNN，单帧 RD，航迹级帧概率平均
- Status: `PLANNED`

## 执行约束

每个实验只运行一轮完整训练，不进行多个随机种子复训。默认随机种子为 `42`。所有实验固定同一 `split.json`、训练帧清单、类别采样策略、CNN 结构、训练轮数、早停策略和评价协议；每个实验使用独立输出目录。

测试集只在方案比较完成后用于最终报告；消融阶段主要比较验证集航迹级 Macro-F1。

## 实验分组

### A：物理速度范围和输出尺寸

| ID | 速度范围 | 输出尺寸 | 说明 |
|---|---|---:|---|
| A0 | `[-90, 89] m/s` | `31×360` | 当前基线，按 `Vr` 坐标插值 |
| A1 | `[-90, 89] m/s` | `31×180` | 低速度分辨率 |
| A2 | `[-90, 89] m/s` | `31×720` | 高速度分辨率 |
| A3 | 约 `[-240,238] m/s` | `31×512/720` | 宽范围 + 原始观测 mask |
| A4 | 约 `[-240,238] m/s` | `31×512/720` | 宽范围，不加 mask |
| A5 | 文件原始宽度 | 直接按列 resize | 仅方法学错误对照，不作为候选正式方案 |

### B：重采样策略

固定 A0 的范围和尺寸，仅改变重采样：

- B0：dB 域线性插值（当前基线）
- B1：线性功率域插值后转回 dB
- B2：区间平均/面积保持下采样
- B3：线性插值 + 观测 mask

### C：归一化策略

- C0：训练集全局均值-标准差（当前基线）
- C1：每帧独立 z-score
- C2：每帧 median/IQR 鲁棒标准化
- C3：训练集分位数裁剪后 min-max
- C4：只做 dB 截断，不标准化

### D：输入通道

- D0：单通道 RD 图
- D1：RD 图 + 观测 mask
- D2：RD 图 + 当前帧峰值位置辅助通道
- D3：RD 图 + 当前帧背景扣除图

### E：模型结构

- R1：轻量 2D CNN，单帧概率平均
- R2：2D CNN + BiGRU，连续 16 帧，注意力池化
- R3：2D CNN + Transformer Encoder，连续 16 帧
- R4：3D CNN，连续 16 帧，可选

### H：学习率

- H0：`0.0003`
- H1：`0.001`
- H2：`0.003`
- H3：`0.01`
- H4：`0.05`
- H5：`0.1`

当前 `lr=0.05` 和 `lr=0.1` 实验归入 H 组，不属于 RD 尺寸消融。

## 推荐执行顺序

```text
A0 → A1/A2/A3/A4
  → B1/B2/B3
  → C1/C2/C3/C4
  → D1/D2/D3
  → R2/R3（R4 可选）
  → H0/H1/H2/H3/H4/H5
```

资源有限时优先执行：`A0、A1、A2、A3、A4、B1、B2、C1、R2、R3`。

## 评价和记录

主要报告航迹级：Macro-F1、准确率、每类 F1、每类召回率和混淆矩阵；同时记录训练时间、显存占用、输入尺寸和是否使用额外 mask。每个实验记录相对 A0 的 Macro-F1 变化。单次运行结果不代表跨随机种子的稳定性，报告中应标注“单 seed、单次运行”。
